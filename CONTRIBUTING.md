# Contributing

Use Python 3.11 or newer. Run `python bench.py validate` before submitting a change. No paid API or live Discord bot is needed.

For a task change, update its written contract, smoke test, grader, and reference together. Keep grading based on externally observable behavior. Explain why each new case matters and show that the broken starter still fails. Do not change a task's contract just to award the reference a passing score.

Use synthetic names and documents. Do not submit chat exports, voice recordings, memory databases, credentials, or third-party study material. Disclose AI assistance in the change description when used.

Scoring changes should explain their effect on previous task versions. These public acceptance tests are inspectable examples; do not describe them as private holdouts or report agent performance without a separate, documented experiment.
